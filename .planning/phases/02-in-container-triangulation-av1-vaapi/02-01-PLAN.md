<objective>
Extend `scratch/repro/harness.sh` with the av1_vaapi measurement instrument's foundation and produce the first two real recorded data points of Phase 2: (1) an empirical capability probe recording which trigger-triad legs the pure VA-API `av1_vaapi` path can actually reproduce on this Arc A380 (D-02), and (2) a determinism-confirmed av1_vaapi self-reference frame for corruption classification (D-04/D-05).

Purpose: Nothing downstream (concurrency measurement, classification, interpretation) is trustworthy until we (a) can invoke a correct full-HW av1_vaapi encode that survives the harness's strict exit-code gate, (b) know which triad legs are active — because per research the B-frame-reorder leg is expected NON-reproducible, which makes the whole phase a PARTIAL-TRIAD data point (D-03), and (c) have an av1_vaapi-specific clean reference (the qsvencc reference is invalid for a different encoder — Pitfall 6).

Output: `vaapi_encode()`, `cmd_probe_vaapi`, `ensure_vaapi_reference`, vaapi scene-lookup helpers, and `probe-vaapi`/`reference-vaapi` dispatcher cases added to `harness.sh`; on-disk `vaapi_probe.txt` and the av1_vaapi self-reference artifacts under `scratch/repro/reference/`.
</objective>
