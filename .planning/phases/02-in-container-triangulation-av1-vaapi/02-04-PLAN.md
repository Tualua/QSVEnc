<objective>
Add the content-origin cross-match (D-09/D-10): a search that, for any corrupt frame, finds its best pixel match among the OTHER two concurrently-running scenes' same-iteration frames — upgrading the finding from "PSNR-drop symptom" to "confirmed cross-session content swap." Apply it to the existing Phase-1 qsvencc corrupt frames (closing the mechanism note Phase 1 explicitly deferred) and wire it into the av1_vaapi corrupt path.

Purpose: Roadmap SC#2 and CONTEXT D-09/D-10 want the triangulation to establish the mechanism, not just the symptom. The Phase-1 summary.txt "Mechanism-vs-symptom NOTE" explicitly deferred cross-session content-origin confirmation to Phase 2. This plan closes that thread using only the Phase-1-proven psnr_of primitive (OpenCL-free, <30 dB threshold) wrapped in a new best-match search loop — no new methodology. The qsvencc cross-match is GPU-free (it only decodes existing .obu files and runs PSNR), so it runs without contending for the Arc GPU; the av1_vaapi wiring reuses the same function on any av1_vaapi corrupt frame (expected zero under the PARTIAL-TRIAD result, which is itself recorded explicitly).

Output: content_cross_match() + cmd_cross_match_qsvencc subcommand + av1_vaapi corrupt-path wiring in harness.sh; on-disk crossmatch_qsvencc.txt confirming (or refuting) cross-session content origin for the Phase-1 corrupt frames.
</objective>
