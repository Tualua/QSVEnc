# Technology Stack

**Analysis Date:** 2026-07-23

## Languages

**Primary:**
- C++17 - Core encoder pipeline (`QSVPipeline/`), CLI (`QSVEncC/`), AviUtl/AviUtl2 plugin (`QSVEnc/`)
- C - Some third-party/embedded code (e.g. `tinyxml2/`, parts of `clRNG/`) and OpenCL kernel host glue

**Secondary:**
- OpenCL C - GPU compute kernels for video filters, `QSVPipeline/rgy_filter_*.cl`, `QSVPipeline/rgy_dummy_load.cl` (custom VPP filter chain: denoise, deband, resize, curves, decimate, afs deinterlace, etc.)
- Batch/Shell scripts - Build automation, `BuildVPL.bat`, `build_vpl.sh`, `build_libdovi.sh`, `build_libhdr10plus.sh`, `build_deb.sh`, `build_rpm.sh`
- Python - Auxiliary tooling only: `PerfMonitor/` (`.pyproj`, performance-monitoring helper referenced from `QSVEnc.sln`), `check_options.py` (doc/option consistency checker at repo root)
- Rust - Bundled/vendored via cargo when building `libdovi` and `libhdr10plus-rs` (see `build_libdovi.sh`, `build_libhdr10plus.sh`)

## Runtime

**Environment:**
- Native compiled binaries — no managed runtime. Two OS targets:
  - Windows (x86/x64) — produces `QSVEncC.exe`/`QSVEncC64.exe` and AviUtl(`.auo`)/AviUtl2(`.auo2`) plugin DLLs
  - Linux (x86_64) — produces `qsvencc` CLI binary

**Package Manager / Build System:**
- **Windows:** MSVC solution `QSVEnc.sln` with per-project `.vcxproj` files (Visual Studio 2022). Sub-projects: `QSVEnc`, `QSVEncC`, `QSVPipeline`, `PerfMonitor`, `tinyxml2`, `clRNG` (see `QSVEnc.sln:6-16`).
- **Linux:** Meson build system, `meson.build` (root, ~950 lines), options in `meson_options.txt`, requires `meson >= 0.61.0`. Also a legacy/simple `makefile` + `configure` script (see `makefile` — `config.mak` generated by `./configure`, per-arch SIMD object rules for SSE2/SSSE3/SSE4.1/AVX/AVX2/AVX512BW).
- Lockfile: none (C++ project; dependencies pinned via git submodules and vendored trees, not a package-manager lockfile)
- **Rust toolchain:** `cargo` + `cargo-c` (`cargo cinstall`) required on Linux to build bundled `libdovi`/`libhdr10plus-rs` when system packages are absent (`meson.build:~330-430`)

## Frameworks

**Core:**
- Intel oneVPL / libvpl (submodule `libvpl/`, built from source via CMake — `build_vpl.sh`, `BuildVPL.bat`, or Meson's bundled-build logic in `meson.build:43-74`) — QSV hardware encode/decode/VPP session API (`ONEVPL_EXPERIMENTAL` enabled, `QSVPipeline/rgy_version.h:70-71`)
- FFmpeg libav* (external, required, dependency('libavutil'|'libavcodec'|'libavformat'|'libavfilter'|'libavdevice'|'libswresample') in `meson.build:89-103`) — demux/mux, decode, audio processing, format I/O (`ENABLE_AVSW_READER`)
- OpenCL (Khronos) — custom GPU filter pipeline, headers required at compile time (`meson.build:76-86`), `ENABLE_OPENCL` conf flag
- clRNG (submodule `clRNG/`, `clRNG.vcxproj` on Windows, `clRNG/src/include` on Linux) — GPU random-number generation used by dithering/deband filters (`QSVPipeline/rgy_filter_deband.cpp`, `QSVPipeline/rgy_filter_deband_gen_rand.cl`, `QSVPipeline/rgy_resource.cpp`)

**Testing:**
- No dedicated unit-test framework/directory detected in the repo. Validation relies on `--check-features` runtime probing (see `GPUFeatures/`) and manual/CI build verification (`.github/workflows/`).

**Build/Dev:**
- CMake — used to build the bundled `libvpl` (oneVPL) submodule, and `libdovi`/`libhdr10plus-rs` Rust crates via `cargo-c`
- Meson + Ninja — primary Linux build orchestrator
- MSBuild (via Visual Studio 2022 / `.vcxproj`/`.sln`) — Windows build
- Docker — reproducible Linux build/packaging environments, `docker/docker_ubuntu2004`, `docker/docker_ubuntu2204`, `docker/docker_ubuntu2404`, `docker/docker_fedora41`, plus `docker/build_ffmpeg_dll.sh`
- `check_options.py` — validates CLI option docs against `rgy_cmd.cpp`/`qsv_cmd.cpp` help text

## Key Dependencies

**Critical:**
- `libvpl` (Intel oneVPL, submodule) - QSV session/encode/decode/VPP core API; statically built and linked (`libvpl.a`)
- FFmpeg libav* 4.x–7.x (system on Linux; prebuilt DLL package `ffmpeg_dlls_for_hwenc` on Windows, downloaded in `Build.en.md:56-58`) - container/codec I/O, avfilter-based readers
- `libva` / `libva-drm` / `libva-x11` / `libdrm` (Linux only, `meson.build:36-41`) - VA-API device/display integration for Intel GPU access
- OpenCL runtime + headers (`intel-opencl-icd` on Linux, `$(INTELOCLSDKROOT)` on Windows) - GPU compute filters
- `clRNG` (submodule) - GPU RNG for deband/dither filters

**Optional (compile-time switchable, `meson_options.txt` / `rgy_version.h` macros):**
- VapourSynth SDK (`enable_vapoursynth`) - scripted frame-server input, headers auto-fetched from GitHub release R72 if missing (`meson.build:106-124,152-186`)
- AviSynth+ SDK (`enable_avisynth`) - scripted frame-server input, headers auto-fetched (AviSynthPlus v3.7.5)
- libass (`enable_libass`) - subtitle burn-in (`ENABLE_LIBASS_SUBBURN`)
- libplacebo + Vulkan (`enable_libplacebo`, `enable_vulkan`) - advanced GPU-based scaling/tone-mapping filter, requires libplacebo API >= 338 (`meson.build:~330-346`)
- OpenVINO C API (`enable_openvino`) - `--vpp-onnx` ONNX model inference filter; headers only at compile time, runtime `.dll`/`.so` loaded dynamically (`QSVPipeline/rgy_filter_onnx.cpp`), headers auto-fetched (OpenVINO 2026.2.0) if absent
- `libdovi` (Dolby Vision RPU parsing, Rust crate) - built via bundled cargo-c if system package absent (`build_libdovi.sh`)
- `libhdr10plus-rs` (HDR10+ metadata, Rust crate) - built via bundled cargo-c if system package absent (`build_libhdr10plus.sh`)
- `libvmaf` - loaded dynamically at runtime via `dlopen`/`LoadLibrary` (never link-time), `QSVPipeline/rgy_libvmaf.cpp`; `ENABLE_VMAF` currently `0` in shipped config (`QSVPipeline/rgy_version.h:116`)

**Infrastructure:**
- `tinyxml2` (submodule/vendored, `tinyxml2/`, own `.vcxproj`) - XML parsing, used by `QSVPipeline/rgy_chapter.cpp` (chapter file parsing)
- `dtl` (submodule, diff-template-library, `dtl/`) - text diffing, used in `QSVPipeline/rgy_cmd.cpp` (option value diagnostics)
- `cppcodec` (submodule, `cppcodec/`) - base64/hex encoding, used in `QSVPipeline/rgy_input_avcodec.cpp`
- `ttmath` (vendored, `ttmath/`) - big-integer/precision math, used in `QSVPipeline/qsv_util.cpp`, `QSVPipeline/qsv_pipeline.cpp`
- `json` (nlohmann::json, vendored header, `json/json.hpp`) - used in `QSVPipeline/rgy_model_registry.cpp` (ONNX model registry metadata)
- `PerfMonitor` (submodule, Python project) - separate performance-monitoring companion tool, not linked into the encoder binary

## Configuration

**Environment:**
- **Windows env vars (build-time, set via `setx`):** `AVISYNTH_SDK`, `VAPOURSYNTH_SDK`, `OPENCL_HEADERS`, `OPENVINO_PATH`, `INTELOCLSDKROOT` — consumed as MSBuild include-path macros in `QSVEncC/QSVEncC.vcxproj:152` etc.
- **Runtime env (Linux):** `LIBVA_DRIVER_NAME` (e.g. `iHD`) selects the VA-API driver; standard `PATH`/`LD_LIBRARY_PATH` for locating `libmfx`/`libvpl`, FFmpeg, and OpenVINO shared libraries
- No `.env` files or secret files detected in the repo (this is a native CLI/plugin project, not a service)

**Build:**
- `meson.build` (root) + `meson_options.txt` - Linux build definition and feature toggles (`enable_vapoursynth`, `enable_avisynth`, `enable_libass`, `enable_libplacebo`, `enable_vulkan`, `opencl_headers`, `enable_openvino`)
- `makefile` + `./configure` (generates `config.mak`) - legacy/alternate Linux build path with explicit per-ISA compile rules (SSE2/SSSE3/SSE4.1/AVX/AVX2/AVX512BW) for `%_<isa>.cpp` sources
- `QSVEnc.sln` + per-project `.vcxproj`/`.vcxproj.filters` - Windows build, configurations `Debug`/`Release`/`DebugStatic`/`RelStatic` (per `Build.en.md:66-71`)
- `QSVPipeline/rgy_version.h` - central version/feature-flag header; defines `VER_STR_FILEVERSION` ("8.22"), encoder identity macros (`ENCODER_QSV=1`, others `0`), and dozens of `ENABLE_*` compile switches shared with the sibling NVEnc/VCEEnc/rkmppenc codebases
- `QSVPipeline/rgy_config.h` (Linux, generated by Meson's `configure_file()` in `meson.build:~455-475`) - mirrors detected FFmpeg API availability and optional-feature results into `#define`s
- `QSVPipeline/rgy_rev.h` (Linux, generated) - embeds `ENCODER_REV` git revision count

## Platform Requirements

**Development:**
- **Windows:** Visual Studio 2022, AviSynth+ SDK, VapourSynth SDK, OpenCL headers (Khronos), optionally OpenVINO Runtime C API headers for `--vpp-onnx`
- **Linux:** C++17 compiler, `meson`+`ninja-build`, `cmake`, `git`, Rust+`cargo`+`cargo-c`, `libva`/`libva-drm`/`libdrm`-dev, `opencl-headers`, FFmpeg 4.x–7.x dev libs, `libass`-dev; Intel GPU media driver (`intel-media-va-driver-non-free`) and `intel-opencl-icd`

**Production:**
- Requires an Intel GPU/APU with Quick Sync Video hardware support and matching Intel graphics driver (Windows Intel Graphics driver; Linux `intel-media-va-driver-non-free` / `iHD` VA-API driver)
- Distributed as: standalone CLI executable (`QSVEncC(64).exe` / `qsvencc`), Debian/RPM packages (`build_deb.sh`, `build_rpm.sh`, `build_pkg/`), and AviUtl (`.auo`, Win32) / AviUtl2 (`.auo2`, x64) plugin DLLs
- CI/release automation: `.github/workflows/build_base_images.yml` (Docker base images), `build_packages.yml` (deb/rpm packaging), `build_releases.yml` (release binaries)
